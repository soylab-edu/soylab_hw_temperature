Windows x64 standalone temperature monitor. Extract the ZIP and run **SoyTemperature.exe** as administrator. No separate .NET installation is required.

- ZIRKA-inspired typography, rulers, thin borders and 60-second temperature traces, with SOYLAB purple and accent colors.
- CPU, GPU and SSD/HDD current/min/max temperatures sampled every 2 seconds.
- CPU and GPU temperature numbers in the system tray. Click to restore; right-click to exit.
- Fonts and cards adapt to window size and DPI. Verified at 225% Windows scaling and compact window size.
- Sensor details, CSV export, history reset and optional official PawnIO driver installation.

CPU sensors require administrator privileges and PawnIO. Storage temperatures depend on hardware/driver SMART support. The tested Apple SSD AP2048 Boot Camp driver does not expose temperature and is shown as unavailable.
